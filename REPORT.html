STANDALONE STOCK JAGUAR · NATIVE INTEGRATION · 2026-10-16

Perspective particles.
Original stereo.

Perspective-sized source sprites, real RGB alpha/additive composition, inherited motion and independently decoded original stereo, alongside native racing, materials, sky, replay and saves.

The request to implement everything is not finished. This build adds perspective RGB sprites, .7 velocity inheritance, conservative native depth queries and full-duration source-channel stereo IMA4 within the stock 6 MiB cartridge. Full angular/quaternion physics, cross-slope tilt, orbit/up-vector camera behavior, full emitter/color fidelity, moving shadows, bloom, shader-equivalent lighting, HRTF/gain fidelity and some presentation still need work. Online services are excluded by the agreed standalone-stock target—not represented by fake local network functions.
All eight current-ROM suites passed: 17 core scenarios, 7 stock desktop scenarios, 2 focused HUD runs, 10 front-end/replay/save scenarios, 4 focused dynamics/effects scenarios, 2 material/sky/stereo scenarios, 4 dedicated falling/pause scenarios, 2 original-stereo/event scenarios and 99 unit tests. Fault controls were rejected; all reports match this ROM hash.

New in this build

  • Perspective-sized source sprite resampling and individual viewport clipping, with native RGB additive sparks/glow and alpha-over clouds.
  • Actual ship-motion velocity inheritance at approximately .7, retained bounded world-space lifetimes and pause.
  • Center-depth queries use real submitted triangle coordinates and vertex Z. A separate native GPU diagnostic ROM tests 12 query cases, including three real rejection results. Driving traces verify depth math, not observed occlusion events.
  • All five full-duration original left/right sources fit the original one-MiB audio slot as stereo IMA4; the DSP independently decodes both channels and retains source content.
  • Source-texel, alpha, RGB, perspective-size, actual TOM pixel, native triangle depth, and exact DSP-source sample proofs.

docs/PARTICLES-AND-ORIGINAL-STEREO.md documents source mapping, compressed-audio quality, memory, fixtures and remaining compromises. This is not per-fragment WebGL, HRTF, or full physics parity.

Retained material and sky integration

  • Original normal/specular maps and six-face sky reflections converted to eight camera-dependent native material banks.
  • Actual scene-triangle sun visibility baked into face luminance, plus real booster-local scene-face illumination.
  • Zero-key ordered-alpha booster, double-sided banner and source-blue speed material.
  • Camera pitch and yaw drive a taller native sky panorama, with split blits at its seam.
  • Original-channel music/destruction without movement panning and spatially balanced wind/boost/collision, with distinct signed-saturating left/right I2S output.
  • Fixed falling displacement at longer frame steps; multiplication operands now respect Jaguar low-16-bit arithmetic.

These are hardware adaptations, not shader/WebAudio equivalence. See docs/MATERIALS-SKY-AND-STEREO.md for source hashes, algorithms, memory layout and remaining fidelity gaps.

Retained native dynamics

  • Actual lateral airbrake drift and decaying map-derived contact impulses.
  • Bilinear height-map hover, active-time falling/destruction and filtered terrain pitch on the original ship and booster meshes.
  • Vertical chase look-at rotation of real rendered vertices and normals. An independent oracle checks actual GPU-transformed and projected ship vertices.
  • Original spark/cloud textures in real world-space collision emitters: a bounded 16-slot pool, one-second lifetimes, fading and pause.
  • Original stern booster glow sprite controlled by speed and boost. The sprite is separate from the new coarse scene-face light; neither implements bloom.
  • Ship/camera pitch stored and interpolated in actual-run replay.

Detailed source mapping, hardware adaptations and limits: docs/DYNAMICS-AND-EFFECTS.md. Particle rendering uses perspective-resampled source art, native RGB additive/alpha-over and a conservative center-depth policy, not a full WebGL pipeline. The sky now follows camera pitch as a cylindrical crop, not a fully rotated cubemap.

Retained systems

  • Original bg.jpg, title.png and Bebas Neue font: native Start, Controls, Local Records, Credits, Replay and result presentation.
  • Controller-only menu navigation. A confirms; Up/Down select; Option returns to Start. Browser layout/settings/transitions are adapted, not reproduced exactly.
  • Genuine native run sampling and elapsed-field interpolation of position, heading, bank and camera. Pause, end hold and Option exit work; replay cannot save a score.
  • Real cartridge EEPROM serial transactions with two-slot journals, checksum/version validation, readback and bounded waits. Manual and autopilot best times remain separate.
  • Existing source-art gauges, countdown, split timing, ship/camera filters and black-screen gates retained.

Actual emulator captures

These are actual Virtual Jaguar output, not illustrative mockups. The menu art is converted from original files. Playback drives the real native mesh/camera; it does not play a video or the supplied static upstream replay.

Persistence proof

A complete native three-lap race wrote and verified nine EEPROM words. A separate emulator process reopened the same CRC-named cartridge EEPROM file and visibly displayed the same saved value. NTSC evidence: total 242000 ms, best lap 80400 ms. PAL is independently tested with field-normalized milliseconds. Replay/menu navigation performs no score writes.

Additional EEPROM-format fault fixtures verify checksum rejection, incomplete-commit fallback, generation wrap and blank storage. They are fault-test inputs, not fabricated race evidence. No host tool patches game RAM.

Replay limits

The last run lives in RAM: 6,144 samples × 64 bytes plus two recorded angle bytes per sample, all ending before the framebuffer. A new countdown replaces it; power-off loses it. A full buffer safely retains a playable prefix. Native chase-camera coordinates are reproduced, not original THREE.js quaternion/orbit behavior. This is bounded native replay, not unlimited persistent recording.

Build and play

make assets    # regenerate all original asset groups
make rom       # GPU/DSP/68000 build + cartridge checks
make test      # all native/core/UI/save/replay and stock GUI gates
make release   # gate, current report and source/ROM archive
virtualjaguar rom/hexgl.j64 --ntsc --gpu --dsp

In a race: A/Up thrust, Left/Right steer, B/Down brake, C autopilot, Pause hold, Option reset/menu. Stock keyboard defaults include L=A, J=C, Z/C=steering, K=B, P=Pause, O=Option; S/X = menu Up/Down and L confirms (or use your configured controller).
