What went wrong

The earlier harness forced the Jaguar BIOS on. Virtual Jaguar defaults to BIOS-off, where the old cartridge entry pointed into GPU data instead of a valid 68000 bootstrap. The BIOS-only passing tests missed that path.

The ROM now includes src/cart_boot.S, a real 68000 bootstrap at $900000. It installs the interrupt acknowledgement loop, copies the existing payload and starts the GPU. The retail-BIOS path is retained. The user's exact emulator configuration was not supplied; this is the confirmed reproduced defect, not proof that all possible black-screen causes have been eliminated.

What now blocks a release

  • Stock GUI: clean settings; default startup; explicit BIOS on/off; PAL/NTSC; real keyboard inputs; OpenGL window captures; start, motion, pause/resume and restart.
  • Core E2E: per-field world pixels through the final frame, native entry and heartbeat, controls/collisions, randomized RAM startup, DSP audio and complete three-lap races in both video standards.
  • Five fault cases: broken entry and frozen desktop process; halted GPU, black video with live game code, and frozen video with live game code in the core harness.
  • Ten watchdog unit tests: including HUD-only output and an otherwise healthy trace going black on its final field.
  • Packaging guard: refuses to bundle unless both complete E2E suites passed for the exact ROM hash. All positive runs are fresh; no saved trace reuse.
